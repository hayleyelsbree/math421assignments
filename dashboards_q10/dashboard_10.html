About this dashboard

This dashboard was built with Quarto. The Overview page shows the main numbers, Flight Analysis analyzes different patterns in flight delays, and Data lets you search the flight list.

In this dataset, there are over 7 million flights from 2024. July had the most total flights, whereas January had the most cancelled flights. We can also see that American Airlines has the highest departure delay. Late Aircraft is responsible for the most delay minutes, which makes sense because if the aircraft is late, it is likely to be the cause of a delay. There is a slight trend with air time versus arrival delay, where an increase in air time tends to lead to a higher arrival delay.

The biggest challenge with this dashboard was the size of the data. Since the dataset has over 7 million records, it would be too computationally expensive to run the analyses on all the data. To combat this issue, I used a sample of 1% of the data, which is still 70,000 records. I also had to use an even smaller subset for the scatterplot because 70,000 records were too many and caused some rendering lag.
